# Celebal Technologies — Data Science Internship Assignments

This repository contains my weekly assignment notebooks for the **Data Science Internship at Celebal Technologies**. Each notebook builds on the previous one, moving from core Python/ML foundations toward deep learning applications in computer vision, NLP, and image reconstruction.

## 📂 Repository Structure

| Notebook | Topic | Key Concepts |
|---|---|---|
| `week1_ankita_priyadarshini.ipynb` | ML Foundations | Python fundamentals, control flow, data structures, exceptions, functions/lambdas, NumPy, Pandas, Linear Algebra, Statistics, Probability Theory |
| `week2_ankita_priyadarshini.ipynb` | End-to-End ML Pipeline (Regression) | Data cleaning, EDA, encoding, feature scaling, feature engineering, sklearn Pipelines, Linear/Ridge/Lasso Regression, model evaluation, hyperparameter tuning, cross-validation, time series forecasting — built on the Tesla deliveries dataset (2015–2025) |
| `week3_ankita_priyadarshini.ipynb` | Clustering & Classification | Data cleaning, correlation heatmaps, boxplot outlier analysis, feature scaling, Elbow Method, K-Means & DBSCAN clustering, PCA visualization, Random Forest & XGBoost classification with hyperparameter tuning, cluster profiling |
| `week4_ankita_priyadarshini.ipynb` | CIFAR-10 Image Classification | ANN vs CNN comparison on the CIFAR-10 dataset — accuracy, loss curves, generalization, and training strategies (dropout, batch normalization, data augmentation) |
| `week5_ankita_priyadarshini.ipynb` | Deep Learning Text Generation | Sequence modeling with Vanilla RNN, LSTM, and GRU — tokenization, n-gram sequence creation, next-word prediction, and text generation |
| `week6_ankita_priyadarshini.ipynb` | Image Denoising Autoencoder | Convolutional autoencoder (PyTorch) trained on MNIST to remove Gaussian noise from images — data loading, noise injection, training loop, and loss visualization |

## 🛠️ Tech Stack

- **Languages:** Python
- **Core Libraries:** NumPy, Pandas, Matplotlib/Seaborn
- **Machine Learning:** scikit-learn (Linear/Ridge/Lasso Regression, Random Forest, XGBoost, K-Means, DBSCAN, PCA)
- **Deep Learning:** TensorFlow/Keras (CNN, RNN/LSTM/GRU), PyTorch (Convolutional Autoencoder)
- **Environment:** Google Colab (all notebooks include an "Open in Colab" badge)

## 🚀 How to Use

Each notebook is self-contained and can be opened directly in Google Colab via the badge at the top of the file, or run locally with Jupyter after installing the relevant libraries (`numpy`, `pandas`, `scikit-learn`, `xgboost`, `tensorflow`/`keras`, `torch`, `matplotlib`, `seaborn`).
